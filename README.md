# eggplant-brownie

[Curso Online Swift parte 1: Desenvolvendo para iOS no Xcode | Alura](https://cursos.alura.com.br/course/swift-desenvolvimento-ios)

Para este curso, é necessário ter configurada a versão 10.1 do Xcode:

* Instale a verão utilizando o xcversion:
` xcversion install 10.1`

* Selecione a versão para realizar o curso:
`xcversion select 10.1`

* Volte à versão anterior quando for trabalhar com outros projetos:
`xcversion select 11.3.1`
